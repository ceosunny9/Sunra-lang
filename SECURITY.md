# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, pull requests, discussions, or commits. Use GitHub's private security advisory workflow for this repository, or contact SunCore Labs LLC through an established private business channel.

Please include a clear description of the issue, affected revision or component, reproduction steps, potential impact, and any suggested mitigation. Do not include live credentials, personal data, or exploit activity against systems you do not own or operate.

## Scope

Security reports are welcome for the parser, compiler pipeline, SunVM, host bindings, cryptographic and provably fair helpers, package tooling, and build artifacts. Reports are evaluated based on reproducibility, impact, and whether they affect supported source revisions.

## Responsible disclosure

Allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Sunra does not make a vulnerability reward commitment through this repository.
