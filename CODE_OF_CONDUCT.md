# Code of Conduct

## Our commitment

Sunra aims to provide a professional, respectful, and technically rigorous collaboration environment. Participants are expected to communicate constructively, evaluate ideas on their merits, and respect differing backgrounds and perspectives.

## Expected behavior

Contributors should use welcoming language, give actionable technical feedback, acknowledge uncertainty, and focus discussion on the work. Harassment, discrimination, intimidation, threats, personal attacks, or disclosure of another person's private information are not acceptable.

## Enforcement

Project maintainers may remove comments, reject contributions, or limit participation when behavior violates this Code of Conduct. Reports should be made privately through an established SunCore Labs LLC contact channel and should include enough detail for a fair review.

## Scope

This Code applies to repository discussions, issues, pull requests, project spaces, and other interactions representing the Sunra community.
